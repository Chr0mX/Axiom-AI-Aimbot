### Types and Errors

Complete type reference and error handling

All public types are re-exported from the crate root. Import them with `use makcu::TypeName`.

### Core Types

| Type          | Kind   | Description                                                                 |
|---------------|--------|-----------------------------------------------------------------------------|
| `Device`      | struct  | Main sync API. `Send + Sync`. See [Connection](https://docs.makcu.k4tech.net/library/connection#connecting). |
| `AsyncDevice` | struct  | Async API. Requires [`async`](https://docs.makcu.k4tech.net/library/features/async) feature. |
| `DeviceConfig` | struct  | [Connection configuration](https://docs.makcu.k4tech.net/library/connection#device-config). |
| `DeviceInfo`   | struct  | Combined port + firmware info. Implements `Display`. See [Device Info](https://docs.makcu.k4tech.net/library/info#device-info). |
| `FireAndForget<'d>` | struct  | [Fire-and-forget](https://docs.makcu.k4tech.net/library/fire-and-forget) RAII guard. Derefs to `Device`. |
| `AsyncFireAndForget<'d>` | struct  | Async [fire-and-forget](https://docs.makcu.k4tech.net/library/fire-and-forget) RAII guard. Derefs to `AsyncDevice`. Requires [`async`](https://docs.makcu.k4tech.net/library/features/async). |

Error Handling

MakcuError and Result

pub type Result<T> = std::result::Result<T, MakcuError>


All fallible methods return makcu::Result<T>. The error type is MakcuError.

MakcuError
Variant List

NotConnected

No active device connection.

Port(serialport::Error)

Serial port error from the underlying driver.

Io(io::Error)

Standard I/O error.

Timeout

Command response timed out. Controlled by command_timeout.

NotFound

No MAKCU device found during auto-detection.

Disconnected

Device disconnected during an operation. See reconnection.

Protocol(String)

Protocol parsing or formatting error.

OutOfRange { value, min, max }

Parameter outside the valid range.
